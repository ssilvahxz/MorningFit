# MorningFit Premium

Versão premium mobile-first do gerador de treino matinal.

## Incluído
- Landing page premium com hero, gradientes e microanimações
- Gerador 10/15/20 minutos
- Mobilidade / Cardio forte
- Circuito automático
- Timer 40s/20s com som
- Área de progresso e recursos
- Login Google preparado para Firebase
- Área ADM reservada ao e-mail `lorielsilvadosreis014@gmail.com`

## Google Login real
Edite `firebase-config.js` com as credenciais do Firebase, ative Google em Authentication e publique o site em um domínio autorizado.

O botão no projeto é uma demonstração enquanto o Firebase não estiver configurado. Em produção, valide o ADM no Firebase/backend e nunca dependa apenas do JavaScript do navegador.

Abra `index.html` para testar o gerador.
